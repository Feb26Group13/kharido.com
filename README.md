# Kharido.com

A Multi-Vendor E-Commerce Platform built using React, Spring Boot, ASP.NET Core, and MySQL.

---

## Project Description

Kharido.com is an online marketplace that allows multiple vendors to sell products on a single platform. Customers can browse products, add items to cart, place orders, make payments, track deliveries, submit reviews, and request returns.

The platform provides dedicated dashboards for Customers, Vendors, and Administrators.
